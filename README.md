# Homebrew tap for ContextSwitcher

[ContextSwitcher](https://github.com/ArtemkaGoldMan/ContextSwitcher) switches your Mac between work
and personal setups in one click, from the menu bar.

```bash
brew install --cask artemkagoldman/tap/contextswitcher
```

Needs an Apple silicon Mac and macOS 13 or later. The app updates itself from
**Settings → Updates**; `brew uninstall --cask contextswitcher` removes it, and adding `--zap` also
removes your profiles and history.
